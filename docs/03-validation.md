# 검증 결과와 중단 판단

## 평가 원칙

1. 겹치는 window를 train과 holdout에 나누지 않고 산책 단위로 분리합니다.
2. 단순 다수 class, 위치 고정, 마지막 속도·방향 유지 기준선과 비교합니다.
3. 평균 점수뿐 아니라 P95, 산책별 승률, 시간당 상태 전환을 봅니다.
4. 학습 성공, 높은 confidence, 최신 version은 제품 가치의 대체물이 아닙니다.
5. 독립 근거가 없으면 `READY`가 아니라 `COLLECTING` 또는 `BLOCKED`로 닫습니다.

## 공개 가능한 집계

- 평가 스냅샷: 10개 산책
- IMU: 1,642,362행
- 펫 GNSS: 31,081행
- 사용자 축 라벨: 749행
- episode: 16행

실제 좌표, 시간축 원본, 사용자·펫 식별자는 공개하지 않습니다.

## PDR

학습·선택에 쓰지 않은 산책의 GNSS를 5초와 10초 구간으로 숨기고 공백 전 정보만으로 끝점을 예측했습니다.

| 공백 | PDR median / P95 | 위치 고정 median / P95 | 마지막 속도·방향 median / P95 |
|---|---:|---:|---:|
| 5초 | 1.34m / 5.91m | 2.73m / 9.92m | 1.53m / 6.87m |
| 10초 | 2.33m / 10.99m | 5.30m / 16.78m | 3.29m / 13.91m |

기준선보다 증분 가치는 있었지만 단일 펫 과거 데이터 결과이므로 제품 경로 권한을 부여하지 않았습니다.

## ML1

초기 probe에서는 일부 축에 통계적 분리 가능성이 보였지만 같은 사용자 정답 구간에서도 시간당 수백 회 상태가 바뀌었습니다. 명시적 walk split으로 재학습한 artifact는 배포 asset과 SHA가 일치했지만 untouched 산책에서 movement macro-F1 0.14, oral 0.07이었습니다.

따라서 문제를 빌드 drift로 돌리지 않았고, 현재 weights의 사용자 가치가 검증되지 않았다고 판정했습니다.

## ML2

희귀 사건의 확정 표본과 독립 train/holdout이 부족했습니다. 탐지율, 선행시간과 시간당 오경보를 계산할 수 없으므로 가치를 주장하지 않았습니다.

## 종료 결정

- 관측 GNSS 산책 기록과 사용자 확인 기억은 보존
- 결정론적 ML0 변환은 연구 자산으로 보존
- PDR은 후보로만 유지
- ML1·ML2 자동 결과는 제품에서 차단
- 하드웨어·ground truth·다중 펫 데이터 재개 조건을 충족하기 전까지 프로젝트 봉인
