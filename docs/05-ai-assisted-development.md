# AI coding agent 사용과 책임 경계

## 사용 사실

KullChip에서는 AI coding agent를 구현, 반복 리팩터링, 테스트 추가와 리뷰 가속에 사용했습니다. 원본 저장소에는 해당 작업 흔적이 있으며 이를 숨기지 않습니다.

## 직접 소유한 책임

- 제품 문제와 사용자 약속 정의
- Phone/Wear 실기기 데이터 수집
- 데이터 권한과 아키텍처 경계 선택
- 모델 합격·차단 기준 정의
- 기준선과 holdout 평가 방식 선택
- 에이전트 결과의 채택·거절
- 제품 노출 차단과 프로젝트 종료 판단

## 검증 원칙

에이전트가 코드를 생성했거나 테스트가 통과했다는 이유만으로 완료로 간주하지 않았습니다. 최종 판단은 다음 증거를 요구했습니다.

- 실제 기기와 실제 산책 데이터
- 독립 산책 단위 holdout
- 단순 기준선 대비 증분 가치
- 시간 안정성·오경보·P95
- RAW lineage와 artifact SHA 일치
- 제품 surface에서의 fail-closed 확인

이 저장소의 목적은 코드량이 아니라 **AI가 만든 결과를 어떤 기준으로 통제했는지**를 보여주는 것입니다.
